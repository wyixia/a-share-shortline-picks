# a-share-shortline-picks · A股短线选股

输入某交易日 T，在全市场（剔 ST、换手 ≥1%、成交额 ≥1 亿）内按已训练的 26 维排序权重打分，输出 Top30 候选名单（CSV + 渲染好的 HTML 报告）。

- 持有口径：**T+1 开盘买入 → T+2 收盘卖出**（B2close）
- 数据主源：随包 westock CLI（腾讯口径），权重与资金流口径一致；快照列表用东财 clist 一次性拉取
- 权重已通过排序层（IC > 0.01、月同向 ≥ 90%）与组合层（IS / OOS-A / OOS-B 三段 TopN 绝对收益为正）双向验证

## 目录结构

```
a-share-shortline-picks/
├── SKILL.md                  作业手册（任务、口径、验证纪律，先读这个）
├── README.md                 本文件
├── cli/                      随包 westock CLI（腾讯口径取数，node 运行）
├── weights/
│   └── 统一三开.json          排序权重（26 维岭回归）
└── scripts/
    ├── 数据准备.py            一键备数：快照 + 近45日全市场日K + 当日资金流
    ├── 出名单.py              出某日候选名单（纯本地计算）
    ├── 训练权重.py            （可选）重训权重
    ├── 补数_历史K线.py        （可选）东财接口回补任意窗口历史 K 线（重训用）
    └── 补数_资金流.py         （可选）腾讯口径资金流长窗口回补（重训用）
```

## 环境要求

- Python 3.x + numpy
- node（运行随包 CLI；路径可用环境变量 `NODE_EXE` 覆盖）
- curl（拉全市场快照列表）
- 数据目录：环境变量 `PICKS_DATA_DIR`，未设则默认本仓库旁的 `picks_data/`（自动创建）

## 快速开始（两条命令）

```bash
python scripts/数据准备.py 2026-09-21   # 首次约 10-15 分钟；之后每天约 5-8 分钟（幂等，已有的跳过）
python scripts/出名单.py 2026-09-21     # 输出 候选_<日期>.csv 与 .html
```

说明：
- 盘中跑 `数据准备.py`，当日因子取"运行那一刻"的快照；正式名单以 14:45 之后的快照为准。
- 资金流为腾讯口径全字段，与权重训练口径一致。

## 数据依赖分层

| 层级 | 内容 | 什么时候需要 | 由谁生成 |
|---|---|---|---|
| **① 出名单·必须** | 快照、历史K线 ≥21 个交易日、T 日K线 | 每个要出名单的交易日；历史K线首次一次 | `数据准备.py <T>` |
| **② 补数·缺了才跑** | 补某日数据断点；长窗口历史K线 | 换机器、数据缺失时；重训前 | `数据准备.py`（幂等补缺）/ `补数_历史K线.py <起> <止>` |
| **③ 重训·才需要** | 历史资金流全字段 + `训练权重.py` + 验证纪律 | 仅重训权重时 | `补数_资金流.py` → `训练权重.py` |

重训产物必须通过 SKILL.md 的验证纪律（IC、月同向、组合三段为正、双向样本外）方可替换 `weights/统一三开.json`。

## 固定参数（不得随意改）

- 池子：全市场剔 ST → 换手 ≥ 1% → 成交额 ≥ 1 亿
- 排序：`weights/统一三开.json`（26 维岭回归）
- 取前 30，**剔封板**（保证名单里的票必然可买）
- 买卖口径：T+1 开盘买 → T+2 收盘卖
- 成本：双边 0.1~0.2%
