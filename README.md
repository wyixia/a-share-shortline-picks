# a-share-shortline-picks · A股短线选股

输入某交易日 T，在全市场（剔 ST、换手 ≥1%、成交额 ≥1 亿）内按已训练的 26 维排序权重打分，输出 Top30 候选名单（CSV + 渲染好的 HTML 报告）。

- 持有口径：**T+1 开盘买入 → T+2 收盘卖出**（B2close）
- 权重已通过排序层（IC > 0.01、月同向 ≥ 90%）与组合层（IS / OOS-A / OOS-B 三段 TopN 绝对收益为正）双向验证

## 目录结构

```
a-share-shortline-picks/
├── SKILL.md                  作业手册（任务、口径、验证纪律，先读这个）
├── README.md                 本文件
├── weights/
│   └── 统一三开.json          排序权重（26 维岭回归）
└── scripts/
    ├── 准备数据.py            一键备数：T 日全市场快照 + 历史K线 + 资金流（当日）
    ├── 出名单.py              出某日候选名单（纯本地计算）
    ├── 训练权重.py            （可选）重训权重，需完整历史数据
    ├── 补数_历史K线.py        （可选）东财接口回补任意窗口历史 K 线（重训用）
    └── 补数_资金流.py         （可选）腾讯口径资金流回补（重训用，自备 westock CLI）
```

## 环境要求

- Python 3.x + numpy
- 数据目录：环境变量 `PICKS_DATA_DIR`，未设则默认本仓库旁的 `picks_data/`（自动创建），路径不写死
- `准备数据.py` 从公开接口（东财行情/K线、腾讯资金流）拉取全部所需数据，无需自建数据管道

## 快速开始（三步）

```bash
pip install numpy
python scripts/准备数据.py 2026-09-18   # 首次约 10~40 分钟；同日重跑只补缺
python scripts/出名单.py 2026-09-18     # 输出 候选_新方案_<日期>.csv 与 .html
```

说明：
- 盘中跑 `准备数据.py`，当日因子取的是"运行那一刻"的快照；收盘后跑即为收盘口径。
- 资金流仅在 T=当日 时拉取（腾讯公开接口只提供当日主力净流入）；历史日期名单照出，"主力净流入"列留空、该因子按中性处理。

## 数据依赖分层

| 层级 | 内容 | 什么时候需要 | 由谁生成 |
|---|---|---|---|
| **① 出名单·必须** | T 日全市场快照、close_snap（名称/股本/ST）、历史K线 ≥21 个交易日 | 每个要出名单的交易日；历史K线首次一次 | `准备数据.py <T>` |
| **② 补数·缺了才跑** | 补某日快照/历史断点；长窗口历史K线 | 换机器、数据缺失时；重训前 | `准备数据.py <T>`（自动补缺，`--force` 重拉）/ `补数_历史K线.py <起> <止>` |
| **③ 重训·才需要** | 历史资金流全字段 + `训练权重.py` + 验证纪律 | 仅重训权重时 | `补数_资金流.py`（自备腾讯 CLI）→ `训练权重.py` |

- 层级 ② 的日常补数只需 `准备数据.py`；`补数_历史K线.py` 仅在重训需要长窗口历史时用。
- 层级 ③ 的资金流回补是**自备项**：需腾讯口径 CLI（`westock_pkg`）与代码清单 `_all_codes.txt`，见脚本头部说明。
- 重训产物必须通过 SKILL.md 的验证纪律（IC、月同向、组合三段为正、双向样本外）方可替换 `weights/统一三开.json`。

## 固定参数（不得随意改）

- 池子：全市场剔 ST → 换手 ≥ 1% → 成交额 ≥ 1 亿
- 排序：`weights/统一三开.json`（26 维岭回归）
- 取前 30，**剔封板**（保证名单里的票必然可买）
- 买卖口径：T+1 开盘买 → T+2 收盘卖
- 成本：双边 0.1~0.2%
